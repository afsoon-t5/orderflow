# OrderFlow — Python Portfolio Demo
سیستم مدیریت سفارش و اتوماسیون فروش با Python/FastAPI.

## اجرا
```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
داشبورد: http://127.0.0.1:8000
مستندات API: http://127.0.0.1:8000/docs

امکانات: داشبورد، ثبت سفارش، تغییر وضعیت، گزارش فروش، REST API و ساختار آماده توسعه برای PostgreSQL، Redis/Celery و Telegram.

این پروژه نمونه‌کار شخصی/دمو است و نباید به‌عنوان پروژه مشتری قبلی معرفی شود.
